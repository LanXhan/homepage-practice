# News Homepage — Frontend Fundamentals Practice

A responsive news homepage built as part of a [Frontend Mentor](https://www.frontendmentor.io/) coding challenge.

This project is a hands-on exercise focused on **strengthening my frontend development fundamentals**, particularly building responsive layouts, working with CSS Grid and Flexbox, and translating static designs into functional web pages.

## Overview

The goal of this project is to recreate the provided News Homepage design as closely as possible while practicing clean, maintainable code and responsive design principles.

Rather than relying on complex libraries or prebuilt UI components, I focused on understanding how layouts, spacing, typography, and interactive states work.

## Tech Stack

- **React** — Component-based UI development
- **Vite** — Development environment and build tooling
- **Tailwind CSS v4** — Utility-first styling
- **JavaScript (JSX)** — Component logic and rendering
- **HTML5** — Semantic page structure

## What I Practiced

### 1. Responsive Web Design
- Building mobile-first layouts
- Using responsive breakpoints
- Adjusting typography, spacing, and layout across screen sizes
- Creating responsive grids for articles and content sections

### 2. CSS Fundamentals
- CSS Grid for multi-column layouts
- Flexbox for navigation and content alignment
- Understanding padding, margins, gaps, and the box model
- Working with typography, colors, and spacing

### 3. React Fundamentals
- Creating reusable components
- Rendering content dynamically using arrays and `.map()`
- Using props and JSX
- Organizing UI into logical sections

### 4. UI Interactions
- Implementing hover and focus states
- Creating smooth CSS transitions
- Adding animated navigation underlines
- Improving visual feedback for interactive elements

## Key Takeaways

This project helped me reinforce the importance of understanding CSS fundamentals before introducing more complex solutions.

Some of the areas I focused on were:

- Understanding how parent containers affect child alignment
- Debugging unexpected padding and spacing
- Choosing between CSS Grid and Flexbox
- Writing responsive Tailwind classes
- Translating visual designs into structured, reusable components
